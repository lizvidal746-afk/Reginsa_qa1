# 📦 Legacy

Esta carpeta contiene documentación **histórica, duplicada o no vigente**.

## ✅ Criterio profesional para mover a legacy
Mover aquí solo cuando:
- Ya **no se usa** en la ejecución actual del proyecto.
- Fue **reemplazado** por una guía nueva en `docs/`.
- Se conserva **solo como referencia**.

## ✅ Dónde debe estar lo activo
Todo lo que **sí se usa hoy** debe estar en `docs/` y en el índice principal.

Si un archivo de `legacy/` vuelve a ser útil para el flujo actual, **muévelo a `docs/`** y actualiza el índice.
