# Scripts de proyecto

Esta carpeta contiene los scripts reales de ejecucion, limpieza y reportes.

Estructura:
- ejecucion/: correr casos y suites.
- limpieza/: limpiar datos y reportes.
- reportes/: abrir reportes.
- utilidades/: helpers de terminal.

Nota:
- Los wrappers antiguos en la raiz fueron retirados para evitar duplicidad.
- Usa los scripts de esta carpeta como referencia unica.
